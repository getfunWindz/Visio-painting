# Visio 内置模具图元名（简体中文 2052）

Office 安装目录：`C:\Program Files\Microsoft Office\root\Office16\Visio Content\2052\`

> 直接用 `Documents.OpenEx` 打开该目录下的文件会报「文件未找到」，必须先复制到可写目录。
> `Stencils` 类会自动完成复制与加载；下表是 `Stencils.master(key, name)` 可用的中文名。

## `loc` → NETLOC_M.VSSX（网络位置）

```
云 | 城市 | 建筑物 | 住宅 | 政府建筑物 | 大学建筑物 | 城镇 | 动态连接线
```

⚠️ 「云」在部分环境下**放置后不渲染**（导出为空白），不要用；改用 `Stencils.cloud()`（内部用 ANNOT 的「修订云形」）。

```
服务器 | 文件服务器 | 电子邮件服务器 | Web 服务器 | 代理服务器 | 实时通信服务器
电子商务服务器 | 数据库服务器 | 内容管理服务器 | FTP 服务器 | 流化媒体服务器
管理服务器 | 目录服务器 | 打印服务器 | 移动信息服务器 | 应用程序服务器 | 动态连接线
```

常用映射：反向代理 → `代理服务器`；业务服务 → `应用程序服务器`；
数据库 → `数据库服务器`；缓存 → `服务器`；对象存储 → `文件服务器`。

## `annot` → ANNOT_M.VSSX（标注）

```
修订云形 | …（其余为各类标注框）
```

「修订云形」是边缘带波浪的封闭云形，可自由填色描边，用作 Internet / 外部平台节点，**渲染稳定**。

## 尺寸与缩放

- 各图元的默认尺寸不同（PC 2.5×2.5cm、防火墙 1.5×2.5cm、云 2.5×1.9cm…），且**包围盒包含底部预留的文字区**。
- 统一用「指定高度」缩放：`drop(..., h_cm=2.0)` 内部按原比例换算宽高。
- 读取实际尺寸只能用 `Shape.BoundingBox(1)`；`BoundingBox(0)` 返回 `(0,0,-1,-1)`。
